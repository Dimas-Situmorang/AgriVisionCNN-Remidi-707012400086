# Model EfficientNet-B0

Letakkan berkas model terlatih dan label kelas di folder ini ketika sudah tersedia, misalnya:

- `agrovision_efficientnet_b0.tflite`
- `labels.txt`

Saat ini aplikasi memakai `EfficientNetB0Service` dalam mode demo agar alur UI dan pencatatan dapat diuji tanpa berkas model.
